## Release notes draft

The text below is a proposed release announcement, to be finalized only after the checklist is complete.

### v0.1.0 — proposed first tagged GitHub release

Vange Workflow is a fixed-role project coordination skill for Codex and Hermes CLI. It helps a project lead route work to registered specialists, track handoffs, check evidence, and manage acceptance gates.

Highlights:

- Fixed-role coordination with explicit ownership and registered task routing.
- Project structure tooling for read-only previews, directory initialization, and intake inspection.
- Hermes-based critical-document review using approved sanitized copies and bounded review rounds.
- Review evidence, no-clobber artifacts, and distinct candidate, formal, and user acceptance gates.
- English and Chinese documentation with installation and getting-started guidance.

Included tooling:

- `scripts/project_intake.ps1`: project intake and structure diagnostics.
- `scripts/initialize_project_structure.ps1`: directory preview and explicit initialization.
- `scripts/review_critical_document.ps1`: the Hermes review adapter.
- Structural, scenario-contract, project-tool, and mock-Hermes validation scripts, plus an opt-in real Hermes smoke script.

Notes:

This is an early-stage open-source project. Feedback and focused contributions are welcome. Installation does not add task-management tools to the Codex client, authorize task creation, or complete project acceptance. The documented setup requires PowerShell 7; the default review configuration uses Hermes CLI and a configured DeepSeek API with `deepseek-v4-pro`. Alternative reviewer CLIs need separately approved and validated adapters. No claim of verified macOS/Linux support, production readiness, or third-party adoption is made.

## Read-only repository checks

Run from the repository root. These checks inspect state; they do not publish anything.

```powershell
git status --short
git rev-parse HEAD
git ls-remote origin refs/heads/main
git ls-remote --tags origin
gh release list --repo Vange-wang/vange-workflow --limit 100
git ls-tree -r --name-only HEAD
```
